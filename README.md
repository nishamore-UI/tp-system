# 🎓 Training & Placement Management System

A web-based Training & Placement Management System developed using Flask and PostgreSQL to manage student placement records with role-based authentication.

## 🚀 Live Demo

🔗 Live Project: https://tp-system-2.onrender.com

## 📌 Features

- 🔐 Admin & Staff Login
- 👨‍🎓 Student Management (CRUD)
- 🔍 Search Students
- 🎯 Filter by Course
- 📊 Filter by Placement Status
- 📈 Dashboard Analytics
- 🥧 Pie Chart
- 📉 Bar Chart
- 📄 CSV Export
- 📑 Pagination
- 📱 Responsive UI

## 🛠️ Technologies Used

- Python
- Flask
- SQLAlchemy
- PostgreSQL (Neon)
- Bootstrap 5
- HTML
- CSS
- JavaScript
- Chart.js
- Gunicorn
- Render

## ⚙️ Installation

```bash
git clone https://github.com/nishamore-UI/tp-system
cd TP-system

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
